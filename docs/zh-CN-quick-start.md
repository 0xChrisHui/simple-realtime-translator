# Simple Realtime Translator 中文上手指南

这是一款用于中英文会议现场的实时字幕翻译工具。常见使用方式是：电脑负责收音和运行网页，投影屏或电视显示实时字幕，现场听众根据字幕理解主讲内容。

## 使用前准备

请确认以下条件已经准备好：

- 使用 Chrome 或 Edge 浏览器。
- 电脑可以正常访问工具页面。
- 麦克风或会议收音设备已经连接到电脑。
- 如果页面要求输入访问码，请向管理员获取。
- 如果要把字幕显示到大屏，请提前连接投影、电视或会议室显示器。

## 第一次打开

1. 打开工具页面。
2. 如果弹出访问码窗口，输入管理员提供的访问码。
3. 浏览器请求麦克风权限时，选择允许。
4. 在顶部的 `Input` 下拉框里选择正确的音频输入设备。
5. 点击 `Start` 开始实时翻译。

看到状态变为 `Live` 后，说明工具已经开始收音和生成字幕。

## 选择字幕视图

顶部有两种显示模式：

- `Focus View`：只显示当前主讲人需要被翻译成的那一种字幕。适合大屏展示，字幕更大、更醒目。
- `Split View`：同时显示英文和中文字幕。适合调试、记录，或现场同时需要查看两种语言时使用。

如果是正式会议展示，建议优先使用 `Focus View`。

## Focus View 的语言切换

`Focus View` 会根据主讲人的语言自动切换字幕方向：

- 主讲人说中文时，重点显示英文翻译。
- 主讲人说英文时，重点显示中文翻译。

为了避免中文讲话中偶尔夹杂几个英文单词导致字幕来回跳动，系统会先等待语言变化稳定一小段时间，再切换显示语言。

## 调整字幕大小

顶部的 `EN Size` 和 `中文 Size` 可以分别调整英文和中文字幕大小。

建议在会议开始前做一次试讲，站在观众观看的位置确认字幕是否足够清楚。大屏展示时，字体可以适当调大；笔记本本机查看时，可以适当调小。

## 使用悬浮字幕

点击 `Floating` 可以打开悬浮字幕窗口。这个模式适合一边播放 PPT，一边把字幕保持在屏幕最前方。

建议使用 Chrome 或 Edge。支持 Document Picture-in-Picture 的浏览器会有更好的置顶效果；如果浏览器不支持，工具会用普通弹窗代替。

## 全屏展示

点击 `Fullscreen` 可以让页面进入全屏模式。正式会议时，建议全屏后再投到大屏，减少浏览器地址栏、标签栏等干扰。

再次点击或按 `Esc` 可以退出全屏。

## 保存字幕记录

点击 `Save` 可以把当前字幕内容保存为本地文本文件。文件会包含英文和中文两部分内容，适合会后整理纪要或做简单留档。

注意：保存的是当前浏览器里已经接收到的字幕内容，关闭页面或刷新页面后，未保存的内容不会自动恢复。

## 停止使用

会议结束后点击 `Stop`。如果不再使用，也可以直接关闭页面。

如果更换了麦克风或会议室收音设备，建议先点击 `Stop`，重新选择 `Input`，再点击 `Start`。

## 现场使用建议

- 正式开始前先试讲 1-2 分钟，确认麦克风、字幕方向和字体大小。
- 尽量让主讲人靠近收音设备，减少背景噪音。
- 如果现场有扬声器播放翻译音频，测试时建议佩戴耳机或降低外放音量，避免麦克风再次收进播放声音。
- 中英文混讲时，尽量保持一句话的主语言清晰，工具会自动处理少量夹杂词。

## 常见问题

**页面没有声音输入权限怎么办？**  
检查浏览器地址栏左侧的权限设置，确认麦克风是允许状态。必要时刷新页面后重新授权。

**字幕没有变化怎么办？**  
先确认状态是否为 `Live`，再检查 `Input` 是否选中了正确的麦克风。如果仍然没有字幕，可以点击 `Stop` 后重新 `Start`。

**Focus View 显示的语言不符合预期怎么办？**  
持续说当前语言几秒钟，系统会在确认语言稳定后切换。如果只是夹杂少量外语单词，系统会尽量保持当前字幕方向不变。

**悬浮字幕没有置顶怎么办？**  
优先使用 Chrome 或 Edge，并确认浏览器允许弹窗。部分浏览器只会打开普通弹窗，置顶效果会受到系统限制。

**访问码错误怎么办？**  
重新打开页面后输入正确访问码，或联系管理员确认当前访问码是否已更新。
