# Simple Realtime Translator 中文上手指南

这是一款用于中英文会议现场的实时字幕翻译工具。常见使用方式是：电脑负责收音和运行网页，投影屏或电视显示实时字幕，现场听众根据字幕理解主讲内容。

## 免费试用

如果你打开的是公共演示站点，无需任何配置即可体验：

1. 保持 Provider 为 `Soniox`、API 输入框留空。
2. 点击 `Try 3 min free`，允许麦克风权限，开始说话即可看到字幕。
3. 顶部会出现 `Trial 3:00` 倒计时徽标，最后 30 秒变红提醒。
4. 3 分钟到时会弹出试用结束卡片；本次字幕已自动保存，可在 `Save` 面板下载。

每位访客每天有 2 次试用机会。想继续使用，有两种方式：

- **自带 key**：到 [Soniox 控制台](https://console.soniox.com/) 注册（注册即送免费额度），把 key 填进顶部 API 输入框，即可不限时使用；
- **自己部署**：见下方「自己部署一套」。

## 使用前准备

请确认以下条件已经准备好：

- 使用 Chrome 或 Edge 浏览器。
- 电脑可以正常访问工具页面。
- 麦克风或会议收音设备已经连接到电脑。
- 如果要把字幕显示到大屏，请提前连接投影、电视或会议室显示器。

## 第一次打开

1. 打开工具页面。
2. 浏览器请求麦克风权限时，选择允许。
3. 在顶部的 `Input` 下拉框里选择正确的音频输入设备。
4. 点击 `Start`（试用模式下为 `Try 3 min free`）开始实时翻译。

看到状态变为 `Live` 后，说明工具已经开始收音和生成字幕。

## 选择字幕视图

顶部有两种显示模式：

- `Focus`：只显示当前主讲人需要被翻译成的那一种字幕。适合大屏展示，字幕更大、更醒目。
- `Split`：同时显示英文和中文字幕。适合调试、记录，或现场同时需要查看两种语言时使用。

如果是正式会议展示，建议优先使用 `Focus`。

## Focus 视图的语言切换

`Focus` 会根据主讲人的语言自动切换字幕方向：

- 主讲人说中文时，重点显示英文翻译。
- 主讲人说英文时，重点显示中文翻译。

为了避免中文讲话中偶尔夹杂几个英文单词导致字幕来回跳动，系统会先等待语言变化稳定一小段时间，再切换显示语言。

## 调整字幕大小

右下角的 `EN` 和 `中文` 输入框可以分别调整英文和中文字幕大小。

建议在会议开始前做一次试讲，站在观众观看的位置确认字幕是否足够清楚。大屏展示时，字体可以适当调大；笔记本本机查看时，可以适当调小。

## 使用悬浮字幕

点击 `Float` 可以打开悬浮字幕窗口。这个模式适合一边播放 PPT，一边把字幕保持在屏幕最前方。

建议使用 Chrome 或 Edge。支持 Document Picture-in-Picture 的浏览器会有更好的置顶效果；如果浏览器不支持，工具会用普通弹窗代替。

## 全屏展示

点击 `FS` 可以让页面进入全屏模式。正式会议时，建议全屏后再投到大屏，减少浏览器地址栏、标签栏等干扰。

再次点击或按 `Esc` 可以退出全屏。

## 保存字幕记录

字幕会自动保存在当前浏览器本地（IndexedDB）。点击 `Stop` 后记录标记为完成；如果页面中途被关闭或刷新，下次打开会以 `Recovered` 状态出现在 `Save` 面板里。

点击顶部 `Save` 打开面板，可以 `Download`（导出 `.txt`，包含英文和中文两部分）、`Delete` 或 `Clear All`。

注意：清除浏览器站点数据、使用无痕模式、更换浏览器或域名，都可能导致本地记录不可见。重要内容请及时下载。

## 停止使用

会议结束后点击 `Stop`。如果不再使用，也可以直接关闭页面。

如果更换了麦克风或会议室收音设备，可以直接在 `Input` 里切换，工具会自动重连并保留当前字幕和记录。

## 自己部署一套

本项目开源（MIT），可一键部署到 Vercel 免费档：

1. 打开 [GitHub 仓库](https://github.com/0xChrisHui/simple-realtime-translator)，点击 README 里的 **Deploy with Vercel** 按钮；
2. 设置环境变量：`SONIOX_API_KEY`（你的 Soniox key）、`SAFETY_SALT`（随机字符串）；只想自己用的话设 `TRIAL_ENABLED=off` 即可；
3. 如果想向访客开放免费试用：设 `TRIAL_ENABLED=full`，在 Vercel Marketplace 添加 Upstash Redis 集成（自动注入连接变量），并把 `ALLOWED_ORIGINS` 设为你的站点地址。

全部环境变量的含义见 README 的 Environment variables 表格。

## 现场使用建议

- 正式开始前先试讲 1-2 分钟，确认麦克风、字幕方向和字体大小。
- 尽量让主讲人靠近收音设备，减少背景噪音。
- 如果现场有扬声器播放翻译音频，测试时建议佩戴耳机或降低外放音量，避免麦克风再次收进播放声音。
- 中英文混讲时，尽量保持一句话的主语言清晰，工具会自动处理少量夹杂词。

## 常见问题

**页面没有声音输入权限怎么办？**
检查浏览器地址栏左侧的权限设置，确认麦克风是允许状态。必要时刷新页面后重新授权。

**字幕没有变化怎么办？**
先确认状态是否为 `Live`，再检查 `Input` 是否选中了正确的麦克风。如果仍然没有字幕，可以点击 `Stop` 后重新 `Start`。

**试用次数用完了怎么办？**
每天的试用配额按 UTC 日期重置。不想等的话，注册一个免费的 Soniox key 填入 API 输入框，或自己部署一套。

**Focus 视图显示的语言不符合预期怎么办？**
持续说当前语言几秒钟，系统会在确认语言稳定后切换。如果只是夹杂少量外语单词，系统会尽量保持当前字幕方向不变。

**悬浮字幕没有置顶怎么办？**
优先使用 Chrome 或 Edge，并确认浏览器允许弹窗。部分浏览器只会打开普通弹窗，置顶效果会受到系统限制。
